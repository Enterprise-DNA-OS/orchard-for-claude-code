# Why the base has no front end

The database holds blocks, spray applications, harvest records, labour allocations, irrigation and tasks. A coding agent reads and changes those records through one CLI. Read-only HTML views and printable documents show the current record without a web application.

A field app offers mobile capture, offline queues, scanning, photos and touch-friendly forms. This base provides none of those and does not replace machine vision, payroll, packhouse processing or export certification. If these are essential to your operation, scope and test them before switching. Enterprise DNA builds the agreed capture screens and connections into your version.

Shared use requires a managed database, named access, permissions and backups. The local embedded database is for one process at a time. Claude Code, Codex, OpenCode and Cursor read the same instructions and use the same records. Agent subscriptions and hosting remain your costs.

Omni by Enterprise DNA installs, customises and runs the agreed system for a setup fee, then a retainer.
